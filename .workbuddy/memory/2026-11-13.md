## v1.01：开对话框时主面板不再消失

现象：右键框 → 文件夹设置 / 添加文件 / 添加文件夹，主面板直接没了（对话框还在）。

根因：面板是 `Qt::Tool | FramelessWindowHint | WindowStaysOnTopHint`，`MainWindow::event()` 里
"WindowDeactivate 且 m_allowAutoHide" 就 hidePanel()。原生文件选择框（`QFileDialog` 静态函数）
不是 Qt 窗口，`QApplication::activeModalWidget()` 那条判断兜不住；对话框激活的瞬间面板已被收走。

修法（确定性，不依赖 Qt 的模态推断）：
- `MainWindow::holdPanel()/releasePanel()` 嵌套计数 `m_panelHold`；`event()` 里 `m_panelHold > 0`
  直接跳过自动收起；模态判断放宽成"存在任何 activeModalWidget"。
- `releasePanel()` 收尾：进来时可见而结束时不可见 → `showPanel()` 拉回来（防止 Windows 把置顶
  工具窗藏掉）；否则 `enableAutoHideSoon(240)` 延后恢复自动收起，躲开关框瞬间补来的那次失焦。
- `showPanel()` 里原来的 220ms 定时器改成 `enableAutoHideSoon(220)`，hold 期间不放开。
- `CanvasWidget` 里加匿名命名空间的 `PanelHold` RAII（构造 `qobject_cast<MainWindow*>(anchor->window())`
  → hold，析构 release），包住 FolderSettingsDialog / WinAppDialog / QInputDialog 重命名 / 参数对话框 /
  `getOpenFileNames` / `getExistingDirectory`；mainwindow 里 openSettings 与首次运行确认框同样处理。

版本：`src/version.h` "1.01"（MINOR 1），`LuoDeck.pro` VERSION = 1.0.1（链接仍是 /VERSION:1.0，
资源 rc 里是 1,0,1,0，正常）。README 当前版本/下载名/版本历史已更；dist/RELEASE_NOTES.md 重写为 v1.01。

## v1.02：热键选中项 / 通知乱码 / 启动弹面板

1. **Ctrl+Alt+L 一直说"没有检测到选中的文件"**。写了个独立诊断程序（`%TEMP%\luodeck_seltest`，
   cl 编译，用 IShellWindows 枚举）实测：Win11 资源管理器带标签页，`IShellBrowser::GetWindow()`
   返回的是标签页视图窗口（`CabinetWClass`/`ShellTabWindowClass`），`GetForegroundWindow()` 是
   外层框架 → `hwnd == foreground || hwnd == foregroundRoot` 永远 false。
   改法：`sameExplorerWindow()` 两边取 `GetAncestor(GA_ROOT)`；多标签用 `GetGUIThreadInfo` 拿
   `hwndFocus` 认出激活标签页（`view->GetWindow()` 与 focus 互相 IsChild）；前台不是资源管理器
   才退回"唯一有选中项的窗口"。实测把 Explorer 提到前台后能正确拿到 `百度网盘.lnk`。
2. **通知横幅应用名乱码**（`Windows 鍥炬爣鍚姩闈㈡澘`）：qmake 自动生成的 `LuoDeck_resource.rc`
   里是 UTF-8 中文但没声明代码页，rc.exe 按 GBK 编译 → exe 的 FileDescription 坏掉。
   改为自备 `LuoDeck.rc`（`#pragma code_page(65001)`，`Translation 0x0804,1200`）+ `.pro` 里
   `RC_FILE = LuoDeck.rc`（设了 RC_FILE，qmake 就不再自动生成）。验证：读 `bin\LuoDeck.exe` 的
   VersionInfo，FileDescription 已是「Windows 图标启动面板」。
3. **启动弹面板**：`main()` 其实从来没 show 面板；真凶是单实例转发里无条件的 `showPanel()`——
   已有实例时再启动一次就弹。改成只在 `add|` 分支 show。实测启动后 EnumWindows 全是 visible=0。

测试技巧（可复用）：`%TEMP%\luodeck_seltest` 下 seltest（枚举+选区）、seltest2（按新逻辑验证）、
winlist（按进程名列顶层窗口的 visible/rect）三个小程序，`build*.bat` 一行 cl 编译。
这台机器上 `Add-Type`（截屏）与 `reg.exe` 都被沙箱拦，改用 C++ 小程序 + 读 exe 的 VersionInfo 最省事；
另外 bash 里带 "PowerShell" 字样的命令会被当成绕过安全检查直接拒。
