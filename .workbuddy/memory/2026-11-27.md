## v1.03：.bat 启动 / 桌面选区热键 / 以管理员身份运行

### 1. `.bat` 点了"没运行"

`Launcher::run()` 里 `.bat/.cmd` 走的是 `startSilent("cmd.exe", {"/c", path})`，而 `startSilent` 会给子进程套
`CREATE_NO_WINDOW` + `STARTF_USESHOWWINDOW/SW_HIDE` → 控制台窗口被整个藏起来。
实测（`%TEMP%\luodeck_seltest\battest.exe`）：旧方式**脚本确实执行了**（会写标记文件），只是全程无窗口，
所以 `start_napcat.bat` 这种要扫码/要 `pause`/要靠控制台挂着的脚本表现成"点了没反应"。

改法：新增 `shellExecute()`（`ShellExecuteExW` + `SEE_MASK_NOASYNC`），`.bat/.cmd` 用 `open` 动词，
和资源管理器里双击一致；带参数时也交给 shell，不再自己拼 `cmd /c ""脚本" 参数"`。`.ps1/.py` 维持静默。

### 2. 桌面选中图标按 `Ctrl+Alt+L` 加不上

根因（诊断程序 `desktest.cpp~desktest4.cpp` 实测）：**Win11 的桌面不在 `IShellWindows` 枚举结果里**，
`get_Count()` 只有 1，就是资源管理器标签页；桌面永远不会出现在循环里。
单独问桌面可以：`FindWindowSW(&VT_EMPTY, &VT_EMPTY, SWC_DESKTOP, ...)` →
`IServiceProvider(SID_STopLevelBrowser)` → `IShellBrowser::QueryActiveShellView` → `GetItemObject(SVGIO_SELECTION)`，
实测能拿到 `C:\Users\w1817\Desktop\Antigravity.lnk`（选区为空时返回 `0x80070490`，属正常）。

改法：`shellselection.cpp` 新增 `isDesktopWindow()`（Progman / WorkerW / GetShellWindow / GetDesktopWindow）
+ `desktopSelection()`；`currentSelection()` 里前台是桌面就直接返回桌面选区（不再退到别的资源管理器窗口）。

顺带修的反馈问题：桌面项进的是「桌面」框，`addApp` 返回子项 id，旧代码拿它 `flashItem` 闪不到任何控件；
现在按 `parentGroupOf` 闪那个框，框被隐藏时给专门提示，已存在的项不再谎报"已加入 N 项"
（`addApp` 新增 `bool *isNew` 出参）。

### 3. 右键「以管理员身份运行」

`Launcher::runAsAdmin()`：`ShellExecuteEx` + `runas` 动词；`.ps1/.py` 先换成 `powershell.exe`/Python 再提权，
`.lnk` 先 `symLinkTarget()` 解出目标，UWP 走 AUMID 激活（无法提权）。菜单加在：画布图标、框内图标、
展开弹层图标——弹层以前**完全没有右键菜单**（`IconTile::contextRequested` 没接），一并补上（打开 / 提权 / 打开位置），
并在 `GroupPopup::event` 里让 `activePopupWidget()` 不算"失活"；菜单动作改成 exec 返回后再 `close()`，
免得在嵌套事件循环里 deleteLater 掉弹层把还在 exec 的 QMenu 一起带走。
