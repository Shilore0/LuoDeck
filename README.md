# LuoDeck

> 一个更快的 Windows 图标启动面板。文件夹框内直接点击、框可拖动、名字与边框颜色可自定义、桌面图标自动收纳。

LuoDeck 常驻托盘，按热键弹出自由布局的图标面板。相对 Windows 开始菜单的改进：

- **文件夹不用点两次**：快捷方式圈进一个「框」，框内图标缩小显示、**直接单击就能启动**，不需要先打开框；
- **框可自定义**：名字、边框颜色都能改（右键 → 文件夹设置），新建框自动分配名字与随机配色；
- **手机桌面式的格子布局**：图标按格点摆放，拖到一起就合成一个**占一格的小文件夹**（里面 4 个缩略图），不会拖成歪的；不想要了就右键「解散」，图标散回面板；
- **不会互相压住**：新加的图标/新框自动找空位落下，**不会盖在「桌面」框上**；拖进框里自动归组，拖出框外变回独立图标；
- **面板贴着内容长**：内容少时不留大片空白，内容多了自动变高，超过屏幕高度可以滚轮滚动；
- **容量可控**：可设 3×3、3×4、4×3 等容量，装不下时最后一格变成「打开」按钮；
- **桌面自动收纳（实时）**：桌面上的快捷方式/程序/文件夹全部自动进入「桌面」框，桌面增删后**1~2 秒内**面板自动跟随，不用重启；容量随图标数量自动扩张；
- **开始菜单已固定的程序直接铺在面板上**：不是塞进框里，而是一个个零散图标（可拖动、可右键删掉，删过的不会再自动冒出来）；
- **不只认 exe**：`.bat` / `.cmd` / `.ps1` / `.py` / `.url` / `.lnk` / 文件夹都能加，脚本启动不闪黑框。
- **Windows 商店应用也能加**：UWP / APPX 应用（如 Armoury Crate）在开始菜单里不是 `.lnk` 而是 `shell:AppsFolder` 下的虚拟条目，
  没有路径可拖——用右键 → **添加 Windows 应用…** 从列表里选，启动走 `IApplicationActivationManager`（按 AUMID 激活），图标取 shell 磁贴图。
- **图标干净**：面板上**不显示快捷方式那个蓝色小箭头**（取图标时刻意不带 `SHGFI_LINKOVERLAY`），
  并且自动裁掉图标四周的透明边再等比撑满格子——不会出现"某个图标莫名其妙特别小"。

## 使用

| 操作 | 效果 |
|---|---|
| 热键（默认 `Ctrl+Space`） | 唤出 / 收起面板（程序启动后**只驻留托盘，不主动弹面板**） |
| **F5** | 一键整理布局：先排框、再排图标，全部按格子重新摆一遍（效果同右键 → 整理布局） |
| 单击框内图标 | 直接启动 |
| 单击框（图标以外的空白/标题区域） | 展开该框，显示全部图标 |
| 按住拖动 | 移动框或单个图标；**松手自动吸附到格子**（手机桌面那种，不会歪着放） |
| 把一个图标拖到另一个图标上 | **两个合成一个文件夹**（2×1，随图标数量自动长大），里面的图标可以直接点；右键可「收成小文件夹」变回一格 |
| 把图标拖进已有的文件夹 | 收进那个文件夹，文件夹会按数量自动调整大小 |
| 右键文件夹 → 收成小文件夹 / 展开为大框 | 一格缩略样式 ⇄ 带标题的展开框（新建/合并出来的默认是展开的） |
| 右键文件夹 → 解散文件夹（图标放回面板） | 删掉文件夹本身，里面的图标散回面板空位 |
| 把文件拖到框上 | 加入该框（拖到哪一格有虚线提示），并在 `groups/<框名>/` 生成 .lnk。「桌面」框除外 |
| 把文件拖到空白处 | 作为独立图标加入面板，自动放在空位 |
| 把面板上的图标拖到框上 | 收进该框 |
| 把框内图标拖到框外 | 变回面板上的独立图标 |
| 滚轮 | 内容比面板高时上下滚动 |
| 右键空白 | **添加文件… / 添加文件夹…** / **添加 Windows 应用…** / 新建文件夹 / **整理布局** / 刷新布局 |
| 右键空白 → 添加 Windows 应用… | 商店 / UWP 应用（Armoury Crate、计算器、Xbox…）没有可拖的文件路径，用这个列表加：可搜索、双击添加、Ctrl 多选 |
| 右键空白 → 整理布局 | 先排**框**（容量大的在前）、再排图标，全部按格子占位摆放，不会互相压住也不会留缝（也可以直接按 F5） |
| 右键空白 → 收拢空位 | 只把空着的格子收掉，**不打乱顺序**（按屏幕上先上下后左右的顺序摆紧），面板宽度也会跟着缩回来 |
| **在框内 / 展开弹层里把图标拖到另一格上** | **调整这个文件夹里的排列顺序**：被拖的图标挪到目标位置，其余顺延；虚线框就是落点提示，顺序写回 `config.json`，重启后保持 |
| 右键框 → **添加文件到此框…** | 选文件直接塞进这个框 |
| 右键框 → 按名称排序 / 清空这个框 | 整理框内图标 |
| 右键框 → 文件夹设置… | 改名字、选边框颜色（系统「桌面」框这两项为灰色不可改） |
| 右键框 → 显示容量 | 自己建的框和系统「桌面」框都能设：2×1 / 2×2 / 3×2 / 3×3 / 3×4 / 4×3 / 4×4 / 5×4，还有「自动（按图标数量）」可改回自动；设过容量后不再被自动调整 |
| 右键图标 | 打开 / 打开所在位置 / **启动参数…** / 重命名 / 移除 |
| 右键图标 → 启动参数… | 弹窗里会写明这个图标的名字、真实路径、快捷方式指向的目标；参数原样接在程序后面：`-server 127.0.0.1:8080`、`"我的 存档"` 都行；`.exe`/`.bat`/`.cmd`/`.ps1`/`.py` 生效，**快捷方式会先解析出目标程序再加参数**；清空即取消 |
| 托盘图标右键 | 显示面板 / **设置** / **导入开始菜单固定项**（可勾选）/ 重新加载 / 打开配置目录 / 退出 |
| 首次运行时的询问 | 「要不要把开始菜单里已固定的程序也放进来？」选一次即定，之后不再打扰 |

## 文件夹与配色

- 框在面板上**顶部显示名字**，展开弹层里也显示；
- 新建文件夹按「文件夹 1、文件夹 2…」自动递增命名，边框颜色从内置 7 色中**随机**取一个；
- 内置配色：黄 `#F2B33D`、蓝 `#4A90D9`、绿 `#4CAF7D`、粉 `#E86A92`、紫 `#9B7EDE`、橙 `#F08A4B`、青 `#48B8C4`；
- **系统「桌面」框**：程序启动时自动创建，默认黄色边框，收纳桌面上所有快捷方式/文件夹，并**实时跟随**桌面增删（目录监听 + 250ms 防抖）。它**不能改名、不能改色、不能删除、不能手动往里加东西**：
  - 把文件拖到它上面 → 文件会加到面板空白处，不会进框（框里只有桌面上真实存在的东西）；
  - 把面板上的图标拖到它上面 → 图标会被挪到最近的空位；
  - 桌面上已有的文件不会在面板顶层重复出现，统一归到框里；
  - 不想看到它：托盘 → 设置 → 勾选「隐藏「桌面」文件夹」（同步仍在后台进行，取消勾选即恢复）；
  - **隐藏后不占地方**：它不再参与面板尺寸和空位计算，藏起来时原位置会顺手收拢一次（只摆紧、不重新排序），面板会跟着变窄；

## 开始菜单导入说明

Windows 11 把「已固定」的列表存在**加密**的 `start2.bin` 和注册表 `Start\Config` 里（同一套加密头，无法直接解析），所以没法精确读到"我 pin 了哪几个"。

LuoDeck 用的是等价信号：**开始菜单 Programs 根目录下的散装 `.lnk` / `.url`**。
Windows 在你把某个程序固定到开始菜单、而它没有现成开始菜单条目时，就是在
`%APPDATA%\Microsoft\Windows\Start Menu\Programs\` 或
`%ProgramData%\Microsoft\Windows\Start Menu\Programs\` 下建一个 `.lnk`，所以这批文件和你看到的「已固定」高度重合（会略多几个）。

- 这些项作为**零散图标**铺在面板上，按行自动排布，避开「桌面」框和你自己放的图标；
- 开始菜单里新增/取消固定，面板 1~2 秒内跟随；
- 不想要的图标：右键 → 从面板移除，会记进 `dismissedPins`，以后不再自动出现；
- **只在第一次运行时问一次**「要不要把开始菜单里已固定的程序也放进来？」：
  - 选「复制过来」→ 立即导入，之后一直跟着开始菜单同步；
  - 选「先不用」→ 什么都不做，不会再问；
  - 想改主意：托盘图标右键 → 勾选/取消「导入开始菜单固定项」（设置里没有这一项，因为它是上手引导，不是长期开关）。

## 数据位置

全部数据在 **`%USERPROFILE%\Documents\LuoDeck`**，整个目录拷走即可迁移：

```
Documents\LuoDeck\
├── config.json            布局（框/图标坐标、名字、颜色、容量、隐藏状态）
├── cache/icons/           图标磁盘缓存（.lnk 图标解析很慢，缓存后启动快）
├── groups\
│   ├── 桌面\              系统框的快捷方式副本
│   │   └── 微信.lnk
│   └── 文件夹 1\
│       └── 终端.lnk
├── themes\                主题
│   ├── default.json
│   └── dark.json
└── i18n\                  多语言
    ├── zh_CN.json
    └── en_US.json
```

`config.json` 结构（v2）：

```json
{
  "version": 2,
  "language": "zh_CN",
  "theme": "default",
  "hotkey": "ctrl+space",
  "iconSize": 48,
  "hideDesktopFrame": false,
  "canvas": { "width": 720, "height": 520 },
  "items": [
    {
      "id": "uuid",
      "type": "group",
      "name": "桌面",
      "system": true,
      "color": "#F2B33D",
      "x": 20, "y": 20,
      "cols": 4, "rows": 4,
      "children": [
        { "id": "uuid", "type": "app", "name": "微信", "path": "C:/...", "x": 0, "y": 0 }
      ]
    },
    {
      "id": "uuid",
      "type": "group",
      "name": "文件夹 1",
      "color": "#4A90D9",
      "x": 285, "y": 20,
      "cols": 3, "rows": 3,
      "children": []
    }
  ]
}
```

- `system: true` 表示系统创建，界面上名字与颜色只读、禁止删除；
- `color` 是边框颜色（`#RRGGBB`）；框底色由该颜色按 10% 透明度自动生成；
- 顶层 `x` / `y` 是画布坐标（像素），但**只会是格点值**：格子原点 16px、横向步长 74px、纵向 82px，
  拖动松手时自动吸附，所以布局永远是整齐的；
- 容量 = `cols × rows`；子项超过容量时前 `容量-1` 个正常显示，最后一格变「打开」；
- `manualGrid: true` 表示这个容量是用户在「显示容量」里手选的，按图标数量自动定大小的逻辑不再覆盖它；
- 框内图标**比外面的小**：格子仍是 62×70（和外面同一套节奏）、但图标只画 28px（外面是 40px），
  一样单击直接启动；框宽 = `列数×74 − 12`、框高 = `行数×82 − 12`，**放到格点上就与外部图标严丝合缝**
  （3×2 的框是 210×152，正好占 3×2 个格子）；
- 框的行数贴着内容走：桌面图标少的时候不会把框撑得老大；
- 文件夹**按图标数量自动定大小**：1~2 个 2×1、3~4 个 2×2、5~6 个 3×2、7~9 个 3×3，
  再多就保持 3×3，最后一格变成「打开」，点开弹层看全部；
- 想自己定格子数：右键框 → **显示容量** 选一个（写入 `manualGrid: true`），之后加/减图标都不会再被自动改大小；
  选「自动（按图标数量）」即可交回自动；给小文件夹设容量会顺手展开成大框；
- 拖动/放大框时，被它压住的图标会被自动挪到空位；框之间也不会互相压住（新建/变大/拖动后会自己找空位）；
- 被收进文件夹的图标不会再被开始菜单同步"补"一份到面板上；
- `compact: true` 表示"小文件夹"：外观跟一个图标一样大（62×70，正好一格），里面显示最多 4 个缩略图，
  点一下弹层看全部；不带 `compact` 的是带标题的大框（如「桌面」框）；
- `canvas.width` 是**面板最大宽度**：面板实际宽度会贴着内容走（最小 420），内容更宽时才用到这个上限；
  `canvas.height` 只在没有任何内容时作为占位，有内容时高度按内容算，超出屏幕就滚动。

## 自定义主题

`themes/` 下新建任意 `.json`，在托盘「设置」里选它。

```json
{
  "name": "Midnight",
  "radius": 12,
  "spacing": 8,
  "colors": {
    "window": "#17181CF2",
    "surface": "#1E1F24",
    "surfaceHover": "#2B2D33",
    "text": "#E8EAED",
    "textMuted": "#9AA0A6",
    "accent": "#7AA2F7",
    "border": "#33363D"
  }
}
```

`accent` 只用于托盘图标与未配色的框；每个框的具体颜色由 `config.json` 的 `color` 决定。

颜色写法是 CSS 风格：`#RRGGBB` 或 `#RRGGBBAA`（**最后两位是透明度**，`F2` ≈ 95%）；
只支持 3/6/8 位，8 位时按 RRGGBBAA 解析（Qt 默认会当成 AARRGGBB，深色主题会变成一片蓝，这里已单独处理）。

主题会作用到**所有窗口**：对话框、输入框、下拉框、列表/表格、菜单、悬浮提示、滚动条、按钮，连**标题栏**也跟着
`surface` / `text` / `border` 上色（Win11 走 `DWMWA_CAPTION_COLOR`，Win10 只切深色标题栏）。
之前列表类控件没被覆盖，深色主题下会沿用系统调色板出现"黑字黑底"，现在统一由主题着色。

## 添加语言

复制 `i18n/zh_CN.json` 改名翻译，再在「设置 → 语言」里选它。系统框的名字走翻译键 `group.desktop`，所以切语言会跟着变。

## 构建

依赖：Qt 6.x（msvc2022_64）、Visual Studio Build Tools 2022（MSVC）、Windows 10/11。

双击 `build.bat`，产物在 `bin\LuoDeck.exe`。Qt 装在别处就改 `build.bat` 顶部的 `QTBIN`。

首次编译后部署 Qt 运行时：

```bat
C:\Qt\6.11.2\msvc2022_64\bin\windeployqt.exe --release --no-translations --no-system-d3d-compiler --no-opengl-sw bin\LuoDeck.exe
```

> `dxcompiler.dll` + `dxil.dll` 约 26MB，纯 Widgets 项目用不到，可删。
> 重新编译前先退出运行中的程序，否则链接会报 `LNK1104`。

## 目录结构

```

build.bat                一键构建
src/
  main.cpp               入口与单实例
  mainwindow.*           面板容器、托盘、设置入口、自动隐藏、滚动
  canvaswidget.*         自由布局画布：拖放、右键菜单、位置持久化
  layoutengine.*         布局计算：占位矩形、找空位（新图标不压框）

  appitemwidget.*        单图标绘制
  groupitemwidget.*      框：标题、边框配色、网格、容量与溢出、拖出拆解
  grouppopup.*           展开的框（显示名称 + 全部图标）
  foldersettingsdialog.* 文件夹设置：改名 + 选颜色（系统框只读）
  icontile.*             框内小图标
  settingsdialog.*       设置：主题 / 语言 / 热键 / Python / 隐藏桌面框 / 开机自启
  appconfig.*            配置读写、桌面同步、分组目录与快捷方式镜像
  theme.*                主题 → QSS
  i18n.*                 多语言
  iconprovider.*         系统图标提取与缓存
  launcher.*             启动分发
  hotkey.*               RegisterHotKey 全局热键
  metrics.h              尺寸常量
```
